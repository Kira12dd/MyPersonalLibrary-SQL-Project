# MyPersonalLibrary-SQL-Project
Це навчальний проєкт бази даних для керування особистою бібліотекою, розроблений у межах курсу з систем керування базами даних

Структура файлів

SQLQuery1.sql — створення таблиць, зв'язків (Foreign Keys) та обмежень (Constraints), представлення (v_FullLibraryReport, v_MyShelf, v_FullLibraryReport).

SQLQuery2.sql — приклади заповнення бази книгами.

SQLQuery3.sql — приклад написання SQL запитів для (ЛР №2)

SQLQuery4.sql — алгоритм розрахунку "цінності" книги через поле Note (ЛР №3)

SQLQuery5.sql — реалізація тригерів для автоматизації аудиту, генерації сурогатних ключів та контролю цілісності (ЛР №4).
